# SupLim_PS_V_0.99 — Superliminal VR

**This VR mod by Project-S Team**

Windows x64 / Steam / OpenVR. Version 0.99 includes the user-verified fix for disappearing walls.

Download **SupLim_PS_V_0.99.zip** from this repository's **Releases** section.
GitHub's automatic “Source code” archives contain this page's files, not the game package.

## Installation (English)

1. Close Superliminal and open its folder through Steam > Properties > Installed Files > Browse.
2. Extract the ZIP contents beside SuperliminalSteam.exe, replacing old mod files.
3. Remove BepInEx/plugins/RadiusUpdateDebug if an older diagnostic build installed it.
4. Connect your headset, start SteamVR, launch the game and press F11 to enable VR.
5. See README.txt inside the ZIP for controls, troubleshooting and removal.

## Установка (Русский)

1. Закройте игру. Откройте её папку: Steam > Свойства > Установленные файлы > Обзор.
2. Распакуйте содержимое ZIP рядом с SuperliminalSteam.exe с заменой файлов мода.
3. Удалите BepInEx/plugins/RadiusUpdateDebug, если ставили прежнюю диагностику.
4. Подключите шлем, запустите SteamVR и игру. Нажмите F11 для включения VR.
5. Управление, решение проблем и удаление описаны в README.txt внутри ZIP.
